Volumetric Color Grading with 3D Texture LUT

This demo uses a single 3D texture (2x2x2) to encode cubic Bézier curves for RGB color grading, as described in the GPU-Based Parametric Curves paper.

Each color channel (R, G, B) is stored as a cubic curve with control points P0, P1, P2, P3. The GPU's trilinear interpolation evaluates the cubic Bézier curve in a single texture lookup!

Key Innovation: Color grading happens at every raymarch iteration, creating volumetric fog with depth-dependent color transformations.

The 3D texture stores 3 piecewise cubic curves (one per RGB channel) in a (6, 2, 2) texture, decoded via trilinear sampling.

Adjust the Bézier control points P1 and P2 for each channel to shape the color response curves. P0 is fixed at 0, P3 is fixed at 1.
